## 设计方案：账簿 -- 个人财务管理系统

### 设计方向

采用双主题设计系统（浅色/深色），默认浅色主题。浅色主题使用清爽的灰白底色 + 琥珀金主色，营造干净专业的财务工具感；深色主题使用暖调深灰底色 + 金色主色，适合夜间使用。两种主题通过 CSS 变量无缝切换，所有颜色、阴影、背景均由变量控制，确保一致性。

### 主题切换机制

- 右上角主题切换按钮（太阳/月亮图标，SVG 内联绘制）
- 点击切换 `body.theme-dark` class
- 用 JS 管理，localStorage 持久化用户偏好
- 所有颜色使用 CSS 变量，`body.theme-dark` 覆写变量值
- 切换带 0.3s 过渡动画

### 字体

- 标题/品牌：Georgia, Songti SC, Noto Serif SC（衬线体，有辨识度，金融气质）
- 正文：-apple-system, PingFang SC, Hiragino Sans GB, Microsoft YaHei, Noto Sans SC（系统字体栈，保证中文渲染质量）
- 数据/金额：SF Mono, Menlo, Consolas（等宽字体，数字对齐）

### 响应式策略

- 桌面端（>1024px）：左侧 240px 固定侧边栏 + 右侧内容区，网格布局 2-4 列
- 平板（768-1024px）：侧边栏保留，卡片网格调整为 1-2 列
- 移动端（<768px）：侧边栏隐藏（汉堡菜单唤出），底部 Tab 导航替代侧边栏，卡片单列，表格横向滚动，内容区底部留 80px 空间给底部导航

### 技术建议

- 组件库推荐：shadcn/ui（与 PRD 一致，暗色主题支持好）
- CSS 方案：Tailwind CSS（PRD 已确定），可直接参考原型中的 CSS 变量体系
- 图表库：Recharts（PRD 已确定），配色可复用本文档的 CSS 变量
- 图标：Lucide React（原型中的 SVG 图标均来自 Lucide 图标集）
- 原型中的设计系统（CSS 变量、间距、圆角、字体大小）可直接转化为 Tailwind 配置和 shadcn/ui 主题
- 主题切换方案：参考原型中 `body.theme-dark` + CSS 变量覆写的方式，可集成到 shadcn/ui 的 theme provider

### 实现说明

- 所有原型为单文件 HTML，CSS/JS 内嵌，无任何外部依赖
- 图标全部使用内联 SVG（来源 Lucide 图标集）
- 图表使用 SVG 手绘，开发时替换为 Recharts 组件
- 模拟数据使用真实中文内容（餐饮、交通、工资等）
- 8 个页面均已通过浏览器验证，浅色/深色两种主题布局正常
- 主题偏好通过 localStorage 持久化
