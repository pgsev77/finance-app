## P0 -- 必须修复

### 1. 支出金额显示为正数（全局 Bug）
- **页面：** 仪表盘、交易列表、交易卡片
- **现象：** 支出交易金额显示为 `+19.00`、`+15.00`，带有 `text-income`（绿色）
- **设计规范：** 支出应为红色（`color-expense: #ea4335`），且不应带 `+` 前缀
- **原因：** 后端返回的 expense 类型 amount 为正值，前端用 `t.amount >= 0` 判断颜色和符号，导致支出也显示绿色和正号
- **修复建议：** 在判断颜色和符号时，根据 `t.type` 区分，expense 统一显示为红色负数（`-19.00`），income 显示为绿色正数（`+19.00`）
  ```tsx
  // 修复逻辑
  const isIncome = t.type === 'income'
  const color = isIncome ? 'text-income' : 'text-expense'
  const sign = isIncome ? '+' : '-'
  const displayAmount = sign + formatMoney(Math.abs(t.amount))
  ```

### 2. 仪表盘统计卡片缺少"净资产/总资产"卡片
- **页面：** 仪表盘
- **现象：** 只有 3 个卡片（本月收入/支出/结余），设计规范中首页应一眼看清资产状况
- **原型对比：** 原型 dashboard.html 包含"总资产"卡片
- **修复建议：** 添加第 4 个统计卡片显示净资产，使用 `color-accent`（琥珀金），调用 `api.getAccounts()` 获取总资产

### 3. 仪表盘缺少"快捷记账"入口
- **页面：** 仪表盘
- **现象：** 没有快捷记账按钮或入口
- **设计规范：** 原型中有醒目的"记一笔"按钮
- **修复建议：** 在统计卡片区域旁添加突出的"记一笔"按钮（金色主色），点击跳转 `/transactions/new`

### 4. 仪表盘缺少周趋势图
- **页面：** 仪表盘
- **现象：** 只有文字列表，没有趋势图
- **设计规范：** 原型包含最近 7 天收支趋势折线图
- **修复建议：** 使用 Recharts 的 AreaChart 或 LineChart，调用 `api.getTrend()` 数据渲染趋势

### 5. 侧边栏导航缺少 Lucide 图标
- **页面：** 全局 Layout
- **现象：** 侧边栏导航项只显示文字，没有图标
- **设计规范：** 原型每个导航项都有对应的 Lucide SVG 图标（仪表盘=LayoutDashboard, 交易=ArrowLeftRight, 账户=Wallet, 分类=Tag, 订阅=CreditCard, 设置=Settings, 用户=Users）
- **修复建议：** 安装 `lucide-react`，在 navItems 中添加 icon 属性并渲染

### 6. 侧边栏导航分组和层级与设计稿不一致
- **页面：** 全局 Layout
- **现象：** 当前实现把 navItems 分为两组（前2个 + moreItems），缺少视觉分组标识
- **设计规范：** 原型侧边栏有明确的分组结构，底部有独立的设置/用户区域
- **修复建议：** 重新组织导航结构，主要导航放上面，底部固定设置和用户信息区域

### 7. 缺少底部导航栏（移动端）
- **页面：** 全局 Layout
- **现象：** 移动端没有底部 Tab 导航
- **设计规范：** 移动端（<768px）应有底部 5-tab 导航，中间记账按钮突出（金色圆形上浮）
- **修复建议：** 添加底部固定导航栏，在 `lg:hidden` 时显示，5 个 tab（首页/交易/记账（突出）/账户/设置），内容区底部预留 80px 空间

### 8. 缺少顶部栏粘性定位
- **页面：** 全局 Layout
- **现象：** 顶部标题栏是静态的，滚动时消失
- **设计规范：** 顶部栏应粘性定位（sticky），毛玻璃背景效果
- **修复建议：** 顶部栏添加 `sticky top-0 z-30 backdrop-blur-md bg-surface/80` 样式

### 9. 登录页缺少品牌视觉元素
- **页面：** 登录页
- **现象：** 登录页只有纯文字标题"账簿"和副标题，缺乏品牌辨识度
- **设计规范：** 原型有衬线体品牌名、精致的登录卡片设计
- **修复建议：** 品牌标题使用设计规范中的衬线字体（Georgia），增大字号和间距，考虑添加装饰性背景元素

## P1 -- 应该修复

### 10. 字体未按设计规范使用
- **页面：** 全局
- **现象：** 全站使用 `-apple-system` 等无衬线字体，品牌名/标题没有使用衬线体
- **设计规范：** 标题/品牌用 Georgia/Songti SC，数据/金额用 SF Mono/Menlo 等等宽字体
- **修复建议：**
  - 品牌名 `.brand` class 使用 `font-family: Georgia, 'Songti SC', 'Noto Serif SC'`
  - 金额数据 `.amount` class 使用 `font-family: 'SF Mono', Menlo, Consolas, monospace`

### 11. 统计卡片缺少 hover 效果
- **页面：** 仪表盘、月度报表、订阅管理
- **现象：** 卡片 hover 时没有视觉反馈
- **设计规范：** 统计卡片应有 `hover 边框变亮 + 阴影加深` 效果
- **修复建议：** 卡片添加 `hover:border-[var(--color-border-light)] hover:shadow-[0_4px_12px_rgba(0,0,0,0.08)] transition-all`

### 12. CSS 变量定义不完整
- **页面：** 全局（index.css）
- **现象：** 设计规范定义了大量 CSS 变量（背景深层、表面悬停、边框亮、弱文字、主色透明、阴影等），当前只定义了基础色
- **缺失变量：** `--color-bg-deep`、`--color-surface-hover`、`--color-border-light`、`--color-text-weak`、`--color-accent-transparent`
- **修复建议：** 补全所有设计规范中的 CSS 变量，确保双主题完整覆盖

### 13. 主题切换使用 class 而非 `body.theme-dark`
- **页面：** 全局
- **现象：** 当前用 `.dark` class 切换深色主题
- **设计规范：** 原型使用 `body.theme-dark` class
- **修复建议：** 保持 `.dark` 也可以，但需确保 Tailwind 的 dark mode 配置为 `class` 策略（已确认没问题），关键是确保所有暗色变量覆盖完整

### 14. 交易列表缺少搜索框
- **页面：** 交易列表
- **现象：** 只有类型筛选，没有搜索框
- **设计规范：** 原型有搜索输入框，支持按备注/分类搜索
- **修复建议：** 在筛选栏添加搜索输入框，支持 debounce 搜索

### 15. 交易列表缺少分类/账户/日期筛选
- **页面：** 交易列表
- **现象：** 只有类型（全部/支出/收入）筛选
- **设计规范：** 原型有类型/分类/账户/日期范围/搜索 五个筛选维度
- **修复建议：** 添加分类下拉选择、账户下拉选择、日期范围选择器

### 16. 订阅管理缺少"新增订阅"按钮和功能
- **页面：** 订阅管理
- **现象：** 只能查看订阅列表，无法新增/编辑/删除订阅
- **设计规范：** 应支持完整的 CRUD 操作
- **修复建议：** 添加新增按钮、表单弹窗或独立页面，支持编辑和删除

### 17. 分类管理缺少新增/编辑/删除功能
- **页面：** 分类管理
- **现象：** 只能查看分类，无法管理
- **设计规范：** 应支持新增自定义分类、编辑名称/图标、删除分类
- **修复建议：** 添加分类 CRUD 操作，包含颜色/图标选择

### 18. 账户卡片缺少月度收支统计
- **页面：** 账户管理
- **现象：** 账户卡片只显示名称和余额
- **设计规范：** 原型账户卡片包含本月收入、本月支出小字统计
- **修复建议：** 在每个账户卡片底部添加"本月收入 / 本月支出"信息

### 19. 账户管理缺少编辑/删除/停用功能
- **页面：** 账户管理
- **现象：** 账户卡片没有操作按钮
- **修复建议：** 卡片添加右上角操作菜单（编辑/停用），长按或点击显示

### 20. 仪表盘订阅提醒只显示 2 条
- **页面：** 仪表盘
- **现象：** `subs.slice(0, 2)` 硬编码最多 2 条
- **修复建议：** 显示全部即将到期订阅，或改为"查看全部"链接

### 21. 缺少转账类型支持
- **页面：** 新增交易
- **现象：** 类型切换只有"支出/收入"两个选项
- **设计规范：** PRD 定义了收入/支出/转账三种类型
- **修复建议：** 添加"转账"选项，转账时显示转出/转入两个账户选择

### 22. 月度报表缺少月份选择器
- **页面：** 月度报表
- **现象：** 只能查看当前月份报表
- **设计规范：** 应支持切换查看不同月份
- **修复建议：** 添加月份前后切换按钮或月份选择器

### 23. 报表图表颜色使用硬编码而非主题变量
- **页面：** 月度报表
- **现象：** 饼图使用硬编码 COLORS 数组，不随主题切换
- **修复建议：** 饼图分类颜色定义为 CSS 变量或使用主题感知的调色板

## P2 -- 可以优化

### 24. 品牌标题字体未使用衬线体
- **页面：** 登录页、侧边栏
- **现象：** "账簿"两字用系统默认无衬线字体
- **设计规范：** 品牌名用 Georgia 等衬线体，"有辨识度，金融气质"
- **修复建议：** 品牌元素添加 `font-serif` class 或直接 `font-family: Georgia, 'Songti SC'`

### 25. 登录页背景过于单调
- **页面：** 登录页
- **现象：** 纯灰白背景，无任何装饰
- **设计规范：** 原型有微妙的渐变和装饰元素
- **修复建议：** 添加微妙的渐变背景或装饰图案，增强品牌感

### 26. 金额未使用等宽字体
- **页面：** 全局
- **现象：** 所有金额数字用普通字体，多位数不对齐
- **设计规范：** 金额应用等宽字体（SF Mono, Menlo, Consolas）确保数字对齐
- **修复建议：** `.amount` 或 `font-mono` class 应用于所有金额显示

### 27. 表格行缺少 hover 高亮效果
- **页面：** 交易列表（桌面端表格）
- **现象：** 有 `hover:bg-bg/50` 但效果太微弱
- **设计规范：** 行 hover 应有明确的高亮反馈
- **修复建议：** 改为 `hover:bg-surface-hover` 或 `hover:bg-[var(--color-surface-hover)]`

### 28. 卡片圆角不一致
- **页面：** 全局
- **现象：** 部分卡片用 `rounded-xl`，部分用 `rounded-lg`
- **设计规范：** 统一圆角 12px（`rounded-xl`）
- **修复建议：** 全局统一使用 `rounded-xl`（12px）

### 29. 加载状态过于简陋
- **页面：** 全局
- **现象：** 所有页面加载时只显示"加载中..."文字
- **修复建议：** 使用 skeleton 加载动画或 spinner，提升等待体验

### 30. 错误处理过于简陋
- **页面：** 全局
- **现象：** 大部分 API 调用的 catch 块为空（`// 静默处理`），失败时无任何反馈
- **修复建议：** 添加 toast 通知或错误提示组件，至少在有数据操作（新增/删除）失败时提示用户

### 31. 分类管理未使用树形展开/折叠交互
- **页面：** 分类管理
- **现象：** 子分类直接平铺展示，没有展开/折叠箭头
- **设计规范：** 原型有展开/折叠箭头，子分类缩进展示
- **修复建议：** 添加 ChevronRight 图标，点击展开/折叠子分类列表

### 32. 移动端侧边栏遮罩关闭体验
- **页面：** 全局 Layout
- **现象：** 移动端侧边栏通过汉堡菜单唤出，但缺少遮罩层点击关闭
- **修复建议：** 侧边栏展开时显示半透明遮罩层，点击遮罩关闭侧边栏

### 33. 主题切换无过渡动画
- **页面：** 全局
- **现象：** 主题切换时颜色突变
- **设计规范：** 切换应带 0.3s 过渡动画
- **修复建议：** 在 body 或根元素添加 `transition: background-color 0.3s, color 0.3s`

### 34. 订阅管理统计卡片与设计稿不一致
- **页面：** 订阅管理
- **现象：** 只有 2 个统计卡片（月均/年预计），设计规范有 3 个（月均/年预计/订阅数量）
- **修复建议：** 添加第三个统计卡片显示活跃订阅数量

### 35. 个人设置页面内容偏少
- **页面：** 个人设置
- **现象：** 只有用户信息、删除确认策略、飞书绑定、修改密码、退出登录
- **修复建议：** 考虑添加：默认货币、默认账户、通知偏好、数据导出入口等

### 36. 订阅管理缺少分类和账户筛选
- **页面：** 订阅管理
- **现象：** 无筛选功能
- **修复建议：** 添加分类和状态筛选

### 37. 缺少空状态插图/引导
- **页面：** 各列表页
- **现象：** 空状态只显示纯文字"暂无xxx"
- **修复建议：** 添加图标或引导操作（如"点击此处添加第一笔交易"）

### 38. 数据表格缺少操作列
- **页面：** 交易列表（桌面端）
- **现象：** 表格没有编辑/删除操作按钮
- **修复建议：** 添加操作列，每行有编辑和删除图标按钮

### 39. 账户类型图标重复（多个银行卡都显示"银"）
- **页面：** 账户管理
- **现象：** 所有银行卡类型都显示"银"字图标，无法区分
- **修复建议：** 使用 Lucide 图标替代单字（Banknote/Wallet/CreditCard 等），或使用账户首字

### 40. 报表页 Trend 图表 Y 轴使用"万"为单位可能导致混淆
- **页面：** 月度报表
- **现象：** `tickFormatter={(v) => \`${v / 10000}w\`}`
- **修复建议：** 改为更清晰的中文格式，如"1.2万"或根据数值大小自动选择单位
